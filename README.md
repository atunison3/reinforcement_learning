# reinforcement_learning

Repository for lessons, Sutton and Barto exercise solutions, and reinforcement-learning projects.

## Repository structure

- `reinforcement_learning/lessons/` — lessons organized around reinforcement-learning concepts.
- `reinforcement_learning/exercises/` — responses to exercises from Sutton and Barto's *Reinforcement Learning: An Introduction*.
- `reinforcement_learning/projects/` — project space for systems and experiments I build.
- `notes/` — chapter study notes.
- `docs/` — the Docsify documentation site.

The installable package also contains shared environments, policies, and learning utilities used by the exercises and projects.
